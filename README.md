# Smart AI Email Assistant

Smart AI Email Assistant is an AI-powered web application designed to analyze email content and identify potential security threats.

The system analyzes an email and provides:

- Email Summary
- Email Type: Safe, Spam, or Phishing
- Priority: High, Medium, or Low
- Sentiment Analysis
- Suggested Reply

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- OpenRouter AI API

## How It Works

User enters an email
        ↓
Frontend
        ↓
Flask Backend
        ↓
AI Model
        ↓
Email Analysis
        ↓
Result Display
        ↓
SQLite Database
